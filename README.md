# Network Security Labs

Hands-on networking and security labs from BS Cyber Security coursework
(Air University), written up as analyst-style reports.

## Labs

| Lab | Focus | Key skills |
|---|---|---|
| [Lab 03 — Network Diagnostics & Incident Analysis](lab-03-network-diagnostics/) | A lab can't reach the LMS: diagnose with `ipconfig`, `ping`, `tracert`, then write an evidence-based incident report | Network troubleshooting, ICMP analysis, route tracing, incident reporting |
| [Lab 04 — Nmap Port Scanning](lab-04-nmap-port-scanning/) | Host discovery, TCP connect scans, and service detection against a local web server | Nmap, port states (open/closed/filtered), service fingerprinting |

## Why these two together

Lab 03 is **defensive**: something is broken, find out why and prove it with
evidence. Lab 04 is **offensive-minded**: map what's exposed before an
attacker does. Together they cover both sides of the same skill —
understanding what the network is actually doing.
